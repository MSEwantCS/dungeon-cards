# 地下城卡牌冒险 · Dungeon Cards

一个 **DND 主题的单文件 Roguelike 卡牌游戏**。选一位英雄，攀登程序生成的地下城，用回合制出牌 + D20 攻击骰击败深处的 Boss。整局约 30 分钟，每次地下城都不同。

> 纯前端、零依赖、零构建——**整个游戏就是一个 `dungeon-cards.html`**，双击用浏览器打开即玩。

## 怎么玩

1. 下载或克隆本仓库。
2. 用任意现代浏览器（Chrome / Edge / Firefox）打开 `dungeon-cards.html`。
3. 选职业 → 选等级 → 进入地下城。

```bash
git clone https://github.com/MSEwantCS/dungeon-cards.git
cd dungeon-cards
# 直接双击 dungeon-cards.html，或：
start dungeon-cards.html      # Windows
open dungeon-cards.html       # macOS
```

> 想在线直接玩，可在仓库 **Settings → Pages** 开启 GitHub Pages，并把 `dungeon-cards.html` 作为首页（或复制一份为 `index.html`）。

## 玩法概览

- **目标**：从地下城底部沿节点路线一路向上，击败顶层 👑 Boss 即通关。
- **地图**：每层若干节点，选择相连路线前进。
  - ⚔️ 战斗　💀 精英（更强，掉遗物）　❓ 未知事件　🎁 宝箱　🔥 篝火（休息/升级）　👑 Boss
- **战斗**：每回合抽 5 张牌、拥有 3 点行动力（⚡）。点击卡牌打出，攻击牌需点击敌人选定目标；回合结束敌人按其**意图**行动。
- **成长**：战斗胜利获得经验，升级提升生命上限与命中，并可从「额外生命 / 回血 / 遗物」中三选一；篝火可回血或永久**升级**一张牌。

## 🎲 D20 攻击骰

每次攻击掷一颗 d20，加你的**命中加值**（`3 + 角色等级/2 + 力量`）对比敌人 **AC**：

| 结果 | 条件 | 效果 |
| --- | --- | --- |
| 暴击 | 天然 20 | 命中且**双倍伤害** |
| 命中 | 骰值 + 加值 ≥ AC | 正常伤害 |
| 落空 | 天然 1，或总值 < AC | 0 伤害 |

多段攻击每段各掷一次骰。敌人身上会显示其 AC，屏幕上会弹出旋转的骰子动画。

## 职业

| 职业 | 生命 | 特色 |
| --- | --- | --- |
| ⚔️ 战士 | 82 | 高生命与护甲，靠力量层层压制 |
| 🧙 法师 | 62 | 脆弱但爆发极高，元素法术清场 |
| 🗡️ 盗贼 | 68 | 连击与毒药，灵活抽牌滚雪球 |
| ✨ 牧师 | 76 | 攻守兼备，治疗续航 + 神圣伤害 |

## 状态效果

- 🛡️ **格挡**：抵消本回合伤害，回合结束清零
- 💪 **力量**：+攻击伤害与命中　🤸 **敏捷**：+格挡值
- 🌀 **虚弱**：造成伤害 −25%　💔 **易伤**：受到伤害 +50%　🧪 **中毒**：每回合掉血

## 操作

- 鼠标点击卡牌 / 敌人 / 地图节点
- `空格`：结束回合
- `Esc`：取消目标选择 / 关闭弹窗
- 顶栏 🔊：音效开关

## 技术说明

- **单 HTML 文件**，内联 CSS 与 JavaScript，无任何外部依赖或构建步骤。
- 音效由 **Web Audio API 实时合成**（无音频文件）；音频在首次点击时自动解锁（浏览器自动播放策略）。
- 战斗动画、骰子、飘字均为原生 DOM + CSS 动画；尊重系统「减少动态效果」设置。
- 卡牌、敌人、遗物、事件均以数据表定义，易于扩展。
